# tree-sitter

Breeze's Markdown editing surface enables GPUI Kit's `tree-sitter-markdown`
feature. That highlighter uses the following MIT-licensed crates, resolved in
`Cargo.lock`:

- `tree-sitter` 0.26.13 — Copyright (c) 2018 Max Brunsfeld
- `tree-sitter-md` 0.5.3 — the tree-sitter Markdown grammars
- `tree-sitter-json` 0.24.8 — the tree-sitter JSON grammar
- `tree-sitter-language` 0.1.7 — the grammar ABI crate
